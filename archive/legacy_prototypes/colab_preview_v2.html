You Are the Agent

A Clinical Decision-Making Exercise Using FHIR

In this exercise, you play the role of a clinical AI agent. You have a clinical question to answer about a patient. Your tools are FHIR queries — structured requests against an electronic health record server.

An AI agent works in a loop:

  1. Observe — what evidence do I have so far?
  2. Decide — what's the most useful query to run next?
  3. Act — execute a FHIR query to retrieve data
  4. Update — add the new evidence to my assessment
  5. Repeat or answer when confident

You'll do this manually, then watch an AI agent handle the same case and compare strategies.

No coding required. Every step uses dropdown menus and Run buttons. After each query, you'll see what FHIR request was made and what came back.

What You'll Practice

  • Describe the agent loop (observe → decide → act → update → repeat)
  • Choose which FHIR resource to query based on what evidence is missing
  • Understand how clinical questions map to structured FHIR queries
  • Explain why a single data point is not enough for classification
  • Decide when evidence is sufficient to answer
  • Compare your query strategy with an AI agent's approach

The Clinical Scenario

Setting: You are an informatics fellow reviewing a cohort of younger patients (age ≤ 35) with a diabetes diagnosis in a synthetic FHIR server.

Problem: Some patients may have been labeled with the wrong diabetes type. Type 1 and Type 2 diabetes require different management, so accurate classification matters.

Your task: For each patient, query the FHIR server and decide:

  • Likely Type 1 — evidence supports autoimmune diabetes
  • Likely Type 2 — evidence supports insulin resistance pattern
  • Unclear — evidence is insufficient or conflicting

Your Toolkit: FHIR Queries as Agent Tools

An agent's "tools" are the actions it can take. In this exercise, each tool is a FHIR query — a structured request to a specific resource endpoint on the EHR server. Here's what you have available:

Available Tools
Tool FHIR Resource What It Returns Why You'd Use It
Get demographics GET /Patient/{id} Name, age, gender, date of birth Basic context about who you're reviewing
Get problem list GET /Condition?subject=Patient/{id} All diagnoses and their clinical status See the full diagnostic picture — autoimmune conditions, complications
Get labs GET /Observation?subject=Patient/{id}&code={LOINC} Lab results sorted by date (most recent first) C-peptide (T1 vs T2), HbA1c (control), BMI (resistance pattern)
Get medications GET /MedicationRequest?subject=Patient/{id} Medication names, status, dates Insulin-only → T1 pattern; oral agents → T2 pattern
Get encounters GET /Encounter?subject=Patient/{id} Visit type, class (ambulatory/inpatient), dates Care context — how recently and where they were seen

FHIR coding systems used: SNOMED CT for diagnoses (46635009 = Type 1 DM, 44054006 = Type 2 DM) • LOINC for labs (4548-4 = HbA1c, 1986-9 = C-peptide, 39156-5 = BMI)

Key insight: An AI agent has exactly these same tools. The difference between you and the AI isn't the tools — it's the strategy for choosing which tool to use next and when to stop.

Discussion Questions

  1. Query strategy: Did you and the AI choose the same FHIR resources? In what order? Which query gave you the most decision-changing information?
  2. Stopping point: Did you query more or fewer resources than the AI? Could either of you have stopped earlier with a confident answer?
  3. FHIR resource value: Which FHIR resource type (Patient, Condition, Observation, MedicationRequest, Encounter) was most informative for this question? Would that change for a different clinical question?
  4. Uncertainty: Did either you or the AI express appropriate uncertainty? What additional FHIR data (if it existed) would resolve the ambiguity?
  5. The agent loop: Now that you've been the agent, describe the loop: observe state → choose FHIR query → execute → update evidence → repeat or answer. What makes this hard to do well?

Wrap-Up

You've experienced the core agent loop from the inside:

while not confident_enough:
    observe current evidence (what FHIR data do I have?)
    choose next FHIR query (which resource will be most informative?)
    execute the query (GET /Resource?parameters...)
    update assessment (does this change my answer?)

This is exactly what an AI agent does — the only difference is who chooses the next query.

To investigate another patient: Go back to Step 3, change the case number, and run through again. Different patients have different evidence patterns.
